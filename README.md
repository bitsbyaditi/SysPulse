#SysPulse
SysPulse is a linux server health and troubleshooting toolkit.
#Goals
-Practice Linux commands 
-Monitor basic server health
-troubleshoot common linux issues 
-learn git and github#current freatures
-checks system uptime
-Display memory swap usage
- checks root disk usage
Displays the number of cpu cores
 
#Usage
Run the health check script with:
 
./scripts/health_check.sh
