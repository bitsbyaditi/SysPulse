SysPulse
SysPulse is a Linux server health-check and troubleshooting toolkit built using Bash scripting. It collects basic system information to help users monitor the health of a Linux server.

Features
Displays system uptime.
Shows memory and swap usage.
Checks root filesystem disk usage.
Displays the number of available CPU processing units.
Prints the date and time when the report is generated.

Technologies Used
Linux
Bash scripting
Ubuntu Server
Git and GitHub

 How to Run
1. Open a terminal in the project directory.
2. Run the script:
   ./scripts/health_check.sh

3. View the health-check report in the terminal.
Example Output
The script displays:
System uptime
 Memory and swap usage
Root filesystem disk usage
CPU count
Report completion message
